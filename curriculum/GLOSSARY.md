## JVM, сборка, инструменты

- **JVM (Java Virtual Machine)** — программа, которая исполняет байткод. Именно она «запускает» Java-программу. *Python:* интерпретатор CPython. → [0](00-setup.md)
- **Байткод** — промежуточный код в `.class`-файлах: не исходник и не машинный код. Одинаков для всех ОС, поэтому «написал один раз — запускай везде». *Python:* `.pyc`. → [0](00-setup.md)
- **`javac`** — компилятор: превращает `.java` в `.class` и по пути проверяет типы. Ошибка типа — это ошибка компиляции, программа даже не запустится. → [0](00-setup.md)
- **JIT (Just-In-Time) компиляция** — JVM замечает часто выполняемые методы и на лету компилирует их в быстрый машинный код. Поэтому Java-приложение первые минуты работает медленнее («прогрев»). → [0](00-setup.md)
- **JDK / JRE** — JDK = всё для разработки (компилятор, инструменты + JRE). JRE = только чтобы запускать (JVM + стандартная библиотека). → [0](00-setup.md)
- **LTS** — версия Java с долгой поддержкой (8, 11, 17, 21, 25). В проде используют их. → [0](00-setup.md)
- **Classpath** — список папок и JAR-файлов, где JVM ищет классы. Нет класса в classpath — `ClassNotFoundException`. *Python:* `sys.path`. → [0](00-setup.md)
- **Пакет (package)** — пространство имён для классов, совпадает со структурой папок: `dev.me.app.User` лежит в `dev/me/app/User.java`. *Python:* пакет/модуль. → [0′](00-java-for-pythonists.md)
- **JAR** — zip-архив с `.class`-файлами и манифестом. Исполняемый JAR запускается `java -jar app.jar`. *Python:* wheel. → [0](00-setup.md)
- **WAR** — JAR для веб-приложений, который кладут в Tomcat. → [М3](03-0-bridge-web-jdbc.md)
- **Maven** — инструмент сборки: качает зависимости, компилирует, запускает тесты, упаковывает. Настраивается в `pom.xml`. *Python:* pip + setuptools + pytest в одном. → [0](00-setup.md)
- **`pom.xml`** — файл описания Maven-проекта: координаты, зависимости, плагины. *Python:* `pyproject.toml`. → [0](00-setup.md)
- **Координаты (GAV)** — `groupId:artifactId:version`, «адрес» библиотеки в Maven-репозитории. → [0](00-setup.md)
- **Артефакт** — то, что производит сборка (JAR/WAR), или библиотека в репозитории. → [0](00-setup.md)
- **Scope зависимости** — где нужна зависимость: `compile` (везде), `test` (только в тестах), `provided` (даст сервер), `runtime` (только при запуске). → [0](00-setup.md)
- **Транзитивная зависимость** — зависимость твоей зависимости. Maven подтягивает её сам. → [0](00-setup.md)
- **BOM (Bill of Materials)** — «прайс-лист» согласованных версий набора библиотек, чтобы не указывать версии по отдельности. → [0](00-setup.md)
- **Жизненный цикл Maven** — фиксированная последовательность фаз: `compile → test → package → verify → install`. → [0](00-setup.md)
- **Maven Wrapper (`mvnw`)** — скрипт в проекте, который скачивает нужную версию Maven. Всем разработчикам — одна версия. → [0](00-setup.md)
- **`~/.m2`** — локальный кеш скачанных библиотек, один на все проекты. → [0](00-setup.md)
- **Project SDK / language level** — в IDEA: какой JDK использовать и какие фичи синтаксиса разрешать. *Python:* выбор интерпретатора в PyCharm. → [0](00-setup.md)
- **`jshell`** — интерактивная консоль Java. *Python:* REPL `python`. → [0](00-setup.md)

## Язык и типы

- **Статическая типизация** — тип каждой переменной известен при компиляции и не меняется. *Python:* type hints, которые реально проверяются, и проверяются всегда. → [0′](00-java-for-pythonists.md)
- **Примитив** — `int`, `long`, `double`, `boolean`, `char`… Хранит значение напрямую, не объект, не может быть `null`. → [0′](00-java-for-pythonists.md)
- **Обёртка (wrapper)** — класс-объект для примитива: `Integer`, `Long`… Нужны, например, для коллекций. → [0′](00-java-for-pythonists.md)
- **Autoboxing / unboxing** — автоматическое превращение `int` ↔ `Integer`. Unboxing `null` → `NullPointerException`. → [0′](00-java-for-pythonists.md)
- **`null` / NPE** — «нет объекта». Вызов метода у `null` → `NullPointerException`. *Python:* `None` и `AttributeError`. → [0′](00-java-for-pythonists.md)
- **`var`** — вывод типа локальной переменной компилятором. Тип всё равно статический, просто не пишешь его руками. → [0′](00-java-for-pythonists.md)
- **Модификаторы доступа** — `private` (только класс), без модификатора = package-private (пакет), `protected` (пакет + наследники), `public` (все). *Python:* `_name` — только соглашение, здесь — запрет компилятора. → [0′](00-java-for-pythonists.md)
- **`static`** — принадлежит классу, а не объекту. `static`-поле — одно на всю программу. → [0′](00-java-for-pythonists.md)
- **`final`** — у переменной/поля: нельзя переприсвоить; у метода — нельзя переопределить; у класса — нельзя наследовать. → [0′](00-java-for-pythonists.md)
- **Конструктор** — метод создания объекта. *Python:* `__init__`. → [0′](00-java-for-pythonists.md)
- **Иммутабельность (неизменяемость)** — объект после создания нельзя изменить. Безопасен для многопоточности, ключей мап, кеширования. *Python:* `frozen=True` dataclass, `tuple`. → [0′](00-java-for-pythonists.md)
- **Защитная копия** — копирование изменяемого объекта (списка) на входе в конструктор / на выходе из геттера, чтобы внешний код не мог испортить внутреннее состояние. → [0′](00-java-for-pythonists.md)
- **Инвариант** — условие, которое всегда истинно для объекта (баланс ≥ 0, ошибок ≤ максимума). Класс обязан его защищать. → [0′](00-java-for-pythonists.md)
- **Контракт** — обещание метода/интерфейса: что принимает, что возвращает, что гарантирует. → [0′](00-java-for-pythonists.md)
- **`equals` / `hashCode`** — сравнение объектов по содержимому и хеш для `HashMap`/`HashSet`. Переопределяются вместе. *Python:* `__eq__` / `__hash__`. → [0′](00-java-for-pythonists.md)
- **`Comparable` / `Comparator`** — «естественный» порядок объектов / внешнее правило сравнения. *Python:* `__lt__` / `key=`. → [0′](00-java-for-pythonists.md)
- **Интерфейс** — контракт без состояния: набор методов, которые класс обязуется реализовать. *Python:* `typing.Protocol` / ABC, но реализация объявляется явно (`implements`). → [0′](00-java-for-pythonists.md)
- **Абстрактный класс** — класс-заготовка с частичной реализацией, объект которого создать нельзя. *Python:* `ABC` с `@abstractmethod`. → [0′](00-java-for-pythonists.md)
- **Перегрузка (overloading)** — несколько методов с одним именем и разными параметрами. В Python её нет. → [0′](00-java-for-pythonists.md)
- **Переопределение (overriding)** — наследник заменяет метод родителя. `@Override` — проверка компилятором. → [0′](00-java-for-pythonists.md)
- **Полиморфизм** — один вызов `shape.area()` работает по-разному в зависимости от реального типа объекта. → [0′](00-java-for-pythonists.md)
- **`sealed`** — класс/интерфейс, у которого фиксированный список наследников. Компилятор знает их все. → [0′](00-java-for-pythonists.md)
- **Pattern matching** — `switch`/`instanceof`, которые одновременно проверяют тип и извлекают значение. *Python:* `match/case`. → [0′](00-java-for-pythonists.md)
- **`record`** — короткое объявление неизменяемого класса данных; `equals/hashCode/toString` генерируются. *Python:* `@dataclass(frozen=True)`. → [0′](00-java-for-pythonists.md)
- **`enum`** — фиксированный набор объектов-констант, у каждой могут быть поля и методы. *Python:* `Enum`, но мощнее. → [0′](00-java-for-pythonists.md)
- **`Optional`** — коробка «значение или пусто» для возвращаемых значений. Заставляет вызывающего подумать об отсутствии. → [0′](00-java-for-pythonists.md)
- **Исключение checked / unchecked** — checked компилятор заставляет поймать или объявить в `throws`; unchecked (`RuntimeException`) — нет. В Python все исключения «unchecked». → [0′](00-java-for-pythonists.md)
- **try-with-resources** — `try (var r = open()) {...}` — ресурс гарантированно закроется. *Python:* `with`. → [0′](00-java-for-pythonists.md)
- **`AutoCloseable`** — интерфейс «меня можно закрыть», нужен для try-with-resources. *Python:* `__exit__`. → [0′](00-java-for-pythonists.md)
- **Трансляция исключений** — поймать низкоуровневое исключение (`SQLException`) и бросить своё, понятное верхнему слою, сохранив причину (`cause`). → [0′](00-java-for-pythonists.md), [М3](03-0-bridge-web-jdbc.md)
- **Generics (обобщения)** — параметры типов: `List<String>`. Компилятор проверяет, что в список строк не положат число. *Python:* `list[str]`, но проверяется. → [0′](00-java-for-pythonists.md)
- **Type erasure (стирание типов)** — после компиляции `List<String>` превращается просто в `List`: параметры типов в рантайме не существуют. → [0′](00-java-for-pythonists.md)
- **Wildcard `?`, `? extends`, `? super`** — «список чего-то», «список T или его наследников», «список T или его предков». → [0′](00-java-for-pythonists.md)
- **PECS** — правило: из коллекции читаешь → `? extends T`; пишешь в неё → `? super T` (Producer Extends, Consumer Super). → [0′](00-java-for-pythonists.md)
- **Raw type** — generic-класс без параметра (`List` вместо `List<String>`). Устаревший опасный стиль. → [0′](00-java-for-pythonists.md)
- **Лямбда** — анонимная функция `x -> x * 2`. *Python:* `lambda`. → [0′](00-java-for-pythonists.md)
- **Функциональный интерфейс** — интерфейс с одним абстрактным методом (`Function`, `Predicate`); лямбда — его реализация. → [0′](00-java-for-pythonists.md)
- **Ссылка на метод** — `String::length` вместо `s -> s.length()`. → [0′](00-java-for-pythonists.md)
- **Effectively final** — переменная, которую не переприсваивают. Только такие можно использовать внутри лямбды. → [0′](00-java-for-pythonists.md)
- **Stream API** — конвейер обработки коллекций: `filter`, `map`, `collect`. Ленивый, одноразовый. *Python:* генераторные выражения + `itertools`. → [0′](00-java-for-pythonists.md)
- **String pool** — JVM хранит одинаковые строковые литералы в одном экземпляре. → [0′](00-java-for-pythonists.md)
- **`StringBuilder`** — изменяемый буфер для сборки строки по кусочкам. *Python:* `"".join(parts)`. → [0′](00-java-for-pythonists.md)
- **`BigDecimal`** — точное десятичное число для денег. `scale` — знаки после запятой, `RoundingMode` — как округлять. *Python:* `decimal.Decimal`. → [0′](00-java-for-pythonists.md), [3](03-currency-exchange.md)
- **`Instant` / `LocalDateTime`** — точный момент во времени (UTC) / «дата и время на часах» без часового пояса. → [0′](00-java-for-pythonists.md)
- **`Clock`** — источник текущего времени, который можно подменить в тестах. → [0′](00-java-for-pythonists.md)

## Коллекции

- **`List` / `ArrayList`** — упорядоченный список на массиве. *Python:* `list`. → [0′](00-java-for-pythonists.md)
- **`LinkedList`** — связный список. Почти никогда не нужен. → [0′](00-java-for-pythonists.md)
- **`Set` / `HashSet` / `LinkedHashSet` / `TreeSet`** — множество: без порядка / в порядке вставки / отсортированное. *Python:* `set`. → [0′](00-java-for-pythonists.md)
- **`Map` / `HashMap` / `LinkedHashMap` / `TreeMap`** — словарь: без порядка / в порядке вставки / отсортированный по ключу. *Python:* `dict` = `LinkedHashMap`! → [0′](00-java-for-pythonists.md)
- **`EnumMap` / `EnumSet`** — быстрые мапа и сет для ключей-enum. → [0′](00-java-for-pythonists.md)
- **`Deque` / `ArrayDeque`** — двусторонняя очередь, для стека и очереди. *Python:* `collections.deque`. → [0′](00-java-for-pythonists.md)
- **`PriorityQueue`** — очередь с приоритетом (куча). *Python:* `heapq`. → [0′](00-java-for-pythonists.md)
- **Бакет, коллизия, load factor** — внутренности `HashMap`: ячейки массива, два ключа в одной ячейке, порог заполненности для расширения. → [0′](00-java-for-pythonists.md)
- **Fail-fast итератор / `ConcurrentModificationException`** — итератор падает, если коллекцию изменили во время обхода не через него. → [0′](00-java-for-pythonists.md)
- **Неизменяемая коллекция** — `List.of(...)`, `List.copyOf(...)`: при попытке изменить — исключение. → [0′](00-java-for-pythonists.md)
- **O(1), O(n), O(log n)** — сложность операции: не зависит от размера / растёт линейно / логарифмически. → [0′](00-java-for-pythonists.md)

## ООП-дизайн и паттерны

- **SOLID** — 5 принципов проектирования классов (ниже по буквам). → [М2](02-0-bridge-oop-design.md)
- **SRP (единственная ответственность)** — у класса одна причина для изменения. → [М2](02-0-bridge-oop-design.md)
- **OCP (открытость/закрытость)** — новое поведение добавляется новым кодом, а не правкой старого. → [М2](02-0-bridge-oop-design.md)
- **LSP (подстановка Лисков)** — наследник должен работать везде, где работает родитель, без сюрпризов. → [М2](02-0-bridge-oop-design.md)
- **ISP (разделение интерфейсов)** — много маленьких интерфейсов лучше одного толстого. → [М2](02-0-bridge-oop-design.md)
- **DIP (инверсия зависимостей)** — зависеть от абстракций (интерфейсов), а не от конкретных классов. → [М2](02-0-bridge-oop-design.md)
- **Инкапсуляция** — спрятать данные и дать наружу только осмысленные операции. → [0′](00-java-for-pythonists.md), [М2](02-0-bridge-oop-design.md)
- **Композиция vs наследование** — «имеет» (объект содержит другой объект) vs «является» (класс расширяет другой). → [М2](02-0-bridge-oop-design.md)
- **Tell, don't ask** — проси объект сделать дело, а не вытаскивай из него данные, чтобы решить снаружи. → [М2](02-0-bridge-oop-design.md)
- **DI (внедрение зависимостей)** — объект получает зависимости снаружи (через конструктор), а не создаёт сам. → [М2](02-0-bridge-oop-design.md), [М4](04-0-bridge-spring-hibernate.md)
- **Composition root** — одно место в программе (обычно `main`), где создаются и связываются все объекты. → [М2](02-0-bridge-oop-design.md)
- **Паттерн проектирования** — типовое решение типовой проблемы дизайна, с названием. → [М2](02-0-bridge-oop-design.md)
- **Strategy** — вынести изменяемый алгоритм в отдельный объект за интерфейсом, чтобы подменять. → [М2](02-0-bridge-oop-design.md)
- **State** — поведение объекта зависит от состояния; каждое состояние — отдельный класс. → [М2](02-0-bridge-oop-design.md)
- **Template Method** — родитель задаёт скелет алгоритма, наследники заполняют шаги. → [М2](02-0-bridge-oop-design.md)
- **Command** — действие как объект: можно хранить в списке, выполнять позже, отменять. → [М2](02-0-bridge-oop-design.md)
- **Factory** — объект/метод, который создаёт другие объекты, пряча детали создания. → [М2](02-0-bridge-oop-design.md)
- **Observer** — подписчики получают уведомления о событиях объекта. → [М2](02-0-bridge-oop-design.md)
- **Singleton** — «единственный экземпляр класса» через статическое поле. Чаще антипаттерн. → [М2](02-0-bridge-oop-design.md), [М3](03-0-bridge-web-jdbc.md)
- **Facade / Adapter / Gateway** — простой интерфейс поверх сложной подсистемы / переходник от чужого интерфейса к своему / объект-«шлюз» к внешней системе. → [М6](06-0-bridge-boot-docker-security.md), [5](05-weather-viewer.md)
- **Chain of Responsibility** — запрос проходит по цепочке обработчиков. Фильтры сервлетов — это она. → [М3](03-0-bridge-web-jdbc.md)
- **Value Object** — объект, определяемый значением, а не идентичностью (деньги, координата). Иммутабелен. → [М2](02-0-bridge-oop-design.md)
- **Rich / Anemic domain model** — логика внутри доменных объектов / объекты — только данные, логика в сервисах. → [4](04-tennis-scoreboard.md)
- **UML-диаграмма классов** — схема классов и связей между ними. → [М2](02-0-bridge-oop-design.md)

## Многопоточность

- **Поток (thread)** — независимая линия выполнения внутри программы. В Java потоки реально работают параллельно (нет GIL!). → [М2](02-0-bridge-oop-design.md)
- **Гонка (race condition)** — результат зависит от того, какой поток успел первым. → [М2](02-0-bridge-oop-design.md)
- **Видимость** — изменения одного потока могут быть не видны другому без синхронизации. → [М2](02-0-bridge-oop-design.md)
- **`synchronized`** — только один поток за раз выполняет блок; даёт и атомарность, и видимость. → [М2](02-0-bridge-oop-design.md)
- **`volatile`** — гарантирует видимость переменной между потоками, но не атомарность `x++`. → [М2](02-0-bridge-oop-design.md)
- **Атомарность / `AtomicInteger`** — операция выполняется целиком, без вмешательства других потоков. → [М2](02-0-bridge-oop-design.md)
- **Happens-before** — правило модели памяти Java: если A happens-before B, то B видит результат A. → [М2](02-0-bridge-oop-design.md)
- **JMM (Java Memory Model)** — правила, что один поток гарантированно видит от другого. → [М2](02-0-bridge-oop-design.md)
- **Busy-wait** — цикл `while (!flag) {}`, жгущий процессор в ожидании. Плохо. → [М2](02-0-bridge-oop-design.md)
- **`ExecutorService` / пул потоков** — готовые потоки, которым отдают задачи. → [М2](02-0-bridge-oop-design.md)
- **`ConcurrentHashMap`** — потокобезопасная мапа. → [4](04-tennis-scoreboard.md)

## Базы данных и доступ к данным

- **JDBC** — стандартный низкоуровневый API Java для работы с SQL-базами. *Python:* DB-API (`sqlite3`, `psycopg`). → [М3](03-0-bridge-web-jdbc.md)
- **`Connection` / `PreparedStatement` / `ResultSet`** — соединение / параметризованный запрос / курсор с результатами. → [М3](03-0-bridge-web-jdbc.md)
- **SQL-инъекция** — атака через подстановку SQL в параметры, если запрос собирается конкатенацией строк. → [М3](03-0-bridge-web-jdbc.md)
- **Пул соединений (HikariCP)** — набор заранее открытых соединений, которые выдаются в аренду. → [М3](03-0-bridge-web-jdbc.md)
- **Транзакция / ACID** — группа операций «всё или ничего» и её гарантии. → [М3](03-0-bridge-web-jdbc.md)
- **Уровень изоляции** — насколько транзакции видят незавершённые изменения друг друга. → [М3](03-0-bridge-web-jdbc.md)
- **Индекс / unique-индекс / внешний ключ** — структура для быстрого поиска / запрет дублей / ссылка на строку другой таблицы. → [М3](03-0-bridge-web-jdbc.md)
- **DAO (Data Access Object)** — класс, в котором собран весь SQL для одной сущности. → [М3](03-0-bridge-web-jdbc.md)
- **Repository** — то же, что DAO, но с интерфейсом «как коллекция объектов». В Spring Data — генерируется. → [М4](04-0-bridge-spring-hibernate.md), [М6](06-0-bridge-boot-docker-security.md)
- **DTO (Data Transfer Object)** — простой объект для передачи данных между слоями/по сети (то, что уходит в JSON). *Python:* pydantic-схема ответа. → [М3](03-0-bridge-web-jdbc.md)
- **Mapper** — код, который перекладывает данные из одного объекта в другой (сущность → DTO). → [М3](03-0-bridge-web-jdbc.md)
- **MVC(S) / слоистая архитектура** — Controller (HTTP) → Service (бизнес-логика) → DAO (SQL). → [М3](03-0-bridge-web-jdbc.md)
- **ORM / Hibernate / JPA** — библиотека, которая сама превращает объекты в строки таблиц и обратно / её реализация / стандарт. *Python:* SQLAlchemy ORM / Django ORM. → [М4](04-0-bridge-spring-hibernate.md)
- **Сущность (Entity)** — класс, отображённый на таблицу. → [М4](04-0-bridge-spring-hibernate.md)
- **Persistence context / сессия Hibernate** — «рабочая область», в которой Hibernate отслеживает загруженные объекты. *Python:* `Session` SQLAlchemy. → [М4](04-0-bridge-spring-hibernate.md)
- **Состояния сущности** — transient (новая), managed (отслеживается), detached (сессия закрыта), removed. → [М4](04-0-bridge-spring-hibernate.md)
- **Dirty checking** — Hibernate сам замечает изменённые поля managed-объекта и пишет `UPDATE` при коммите. → [М4](04-0-bridge-spring-hibernate.md)
- **Lazy / Eager loading** — связанные объекты грузятся при первом обращении / сразу. → [М4](04-0-bridge-spring-hibernate.md)
- **`LazyInitializationException`** — обращение к ленивой связи после закрытия сессии. → [М4](04-0-bridge-spring-hibernate.md)
- **Проблема N+1** — 1 запрос за списком + по запросу на каждый элемент за связанными данными. → [М3](03-0-bridge-web-jdbc.md), [М4](04-0-bridge-spring-hibernate.md)
- **`JOIN FETCH` / `@EntityGraph`** — способы загрузить связи одним запросом. → [М4](04-0-bridge-spring-hibernate.md)
- **Пагинация (offset / keyset)** — выдача данных страницами: «пропусти N» / «после такого-то ключа». → [4](04-tennis-scoreboard.md)
- **Миграции (Flyway / Liquibase)** — версионированные SQL-скрипты изменения схемы. *Python:* Alembic / Django migrations. → [5](05-weather-viewer.md)
- **Оптимистическая блокировка / `@Version`** — проверка при записи, что никто не изменил строку с момента чтения. → [4](04-tennis-scoreboard.md)
