# Программа обучения

Основа — роадмап [zhukovsd/java-backend-learning-course](https://zhukovsd.github.io/java-backend-learning-course/)
(ТЗ проектов, матрица навыков, чеклисты). Поверх него — модули с теорией, вехами, челленджами
и акцентом на ООП, паттерны и вопросы собеседований.

## Принципы

1. **Код пишешь только ты.** Я даю направление, критикую, задаю вопросы.
2. **Вехи маленькие, ревью жёсткое.** Проще исправить 200 строк, чем 2000.
3. **Java-way, не Python-way.** Каждый питонизм — замечание. Цель — писать код, который на ревью в Java-команде
   не вызовет вопросов.
4. **Собеседование — постоянный фон.** Каждая тема подаётся с угла «как это спросят и как правильно ответить».
5. **Не читать чужие реализации** до работающей своей версии (правило курса). Чеклисты самопроверки из ТЗ —
   тоже после первой работающей версии.

## Как устроен каждый модуль проекта

1. **ТЗ** — кратко и ссылка на оригинал.
2. **Цели обучения.**
3. **Что изучить до старта** — с пометками «из Python ты знаешь X, обрати внимание на Y».
4. **Паттерны и принципы в фокусе** — где они естественно возникают (без готового дизайна).
5. **Вехи** — цель, вопросы до кода, критерии приёмки. Сдаёшь каждую по отдельности.
6. **Челленджи** ★ / ★★ / ★★★ — сверх ТЗ. ★ — желательно, ★★ — если хочешь сильный проект в резюме,
   ★★★ — на вырост.
7. **За что будет 🔴** — категории ошибок.
8. **Контрольные вопросы** — «защита» проекта в формате собеседования.

По тексту — блоки:
- 🎯 **Спросят на собесе** — вопрос, короткий правильный ответ, типичная ошибка.
- ⚠️ **Типичная ловушка** — где новички (особенно из Python) стреляют себе в ногу.

## Литература (сквозная)

Основное — выбери одно из «базы» и читай параллельно проектам 0′–2:
- **Кей Хорстманн, «Java. Библиотека профессионала», т. 1** (или *Core Java, Vol. I*) — база, 12-е изд. и новее (Java 17+).
- **Джошуа Блох, «Effective Java», 3-е изд.** — обязательно. Читать главами по мере проектов, ссылки в модулях.
- **Брайан Гётц, «Java Concurrency in Practice»** — к проектам 2 и 4 (главы 1–5).
- **Мартин Фаулер, «Patterns of Enterprise Application Architecture»** — к проектам 3–5 (Domain Model, DAO/Repository,
  DTO, Unit of Work, Identity Map).
- **«Head First. Паттерны проектирования»** или [refactoring.guru/ru/design-patterns](https://refactoring.guru/ru/design-patterns) — справочник по GoF.
- **Влад Михалча, «High-Performance Java Persistence»** + его блог — к проектам 4–6.
- Раздел [технологий курса](https://zhukovsd.github.io/java-backend-learning-course/technologies/java/) — подборка ресурсов автора роадмапа.
