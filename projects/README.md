# Твои проекты

Каждый проект — отдельный Maven-проект:

```
projects/
├── 00-hello/                 # чекпоинт окружения
├── 01-hangman/
├── 02-simulation/
├── 03-currency-exchange/
├── 04-tennis-scoreboard/
├── 05-weather-viewer/
├── 06-cloud-file-storage/
└── 07-task-tracker/
```

Правила:
- `groupId` — единый для всех проектов (например, `dev.<твой-ник>`), пакеты — `dev.<ник>.<проект>`.
- В корне каждого проекта свой `README.md`: как запустить, какие переменные окружения нужны.
- `target/`, `.idea/`, `*.iml` не коммитим (см. корневой `.gitignore`).
- Секреты (API-ключи, пароли) не коммитим никогда. Только через переменные окружения/`.env`, который в `.gitignore`.
