# Java Teacher

Персональная программа изучения Java по проектам роадмапа
[zhukovsd/java-backend-learning-course](https://zhukovsd.github.io/java-backend-learning-course/)
с ментором-ревьюером (Claude). Ментор **не пишет код решения**: он даёт теорию, наводящие вопросы, вехи,
челленджи и жёстко проверяет результат.

## Структура

| Путь | Что там |
|------|---------|
| [`CLAUDE.md`](CLAUDE.md) | Правила ментора: что можно и нельзя, формат ревью, уровень строгости |

## Порядок

0. [`curriculum/00-setup.md`](curriculum/00-setup.md) — окружение: JDK, Maven, IntelliJ IDEA.
1. [`curriculum/00-program.md`](curriculum/00-program.md) — общая программа, карта навыков.
2. [`curriculum/00-java-for-pythonists.md`](curriculum/00-java-for-pythonists.md) — перестройка мышления с Python на Java.
3. Проекты 1–7 по порядку.

## Рабочий цикл

1. Открыть модуль проекта, изучить раздел «Что изучить до старта». Можно попросить ментора:
   *«погоняй меня по теории перед проектом N»*.
2. Взять очередную веху. Перед кодом ответить себе на вопросы из вехи.
3. Реализовать, закоммитить в `projects/<NN-name>/` (осмысленные коммиты, не «fix»).
4. Написать в чат: **«сдаю веху N.M»**. Ментор соберёт проект, прогонит тесты, напишет ревью в `reviews/`.
5. 🔴 есть → исправить и сдать повторно. 🔴 нет → следующая веха (🟡 можно закрывать параллельно).
6. После последней вехи — **защита**: контрольные вопросы модуля + чеклист самопроверки из ТЗ курса.

## Как просить помощь

- «Не понимаю, с чего начать веху N.M» → получишь наводящий вопрос.
- «Ещё подсказку» → следующая ступень (концепция/паттерн → структура словами).
- «Объясни тему X» → теория с параллелями к Python и пометками для собеса.
- Готового кода не будет. Это не вредность, а смысл всей затеи.
